# 0003. BIZ 默认模板策略

- Status: Accepted
- Date: 2026-10-29

## Context

业务单号需要可读、可校验、可日切；默认值必须安全且符合常见财务/订单场景。

## Decision

- 默认校验算法：`MOD37_36`（ISO 7064，支持 0-9A-Z）；
- 默认日切：`DAILY`，按 `biz.zone-id` 的本地日期；
- 序列耗尽：抛 `KNITID-2005`，不自动回绕/等待；
- 默认序列：`memory`（单实例），多实例必须显式改为 `redis` 或自定义。

## Consequences

- 单实例默认可用；多实例若忘记配置序列会重复，文档/FAQ 必须醒目提示；
- 校验位默认存在，模板含 `{check}` 时算法不能为 `NONE`。
