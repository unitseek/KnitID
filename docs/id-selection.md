## 常见误区

- UUIDv7 不等于 UUIDv4：时间有序，可能暴露生成时间；
- ULID 大小写：输出大写，读取需兼容；
- KSID 多实例必须分配唯一 WorkerId；
- BIZ 的 `seq` 不是全局唯一；
- 不要把可枚举序列用于令牌/密码。
